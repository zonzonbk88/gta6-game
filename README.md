An original open-world driving game that runs in the browser, built by an AI agent for make.fun's GTA6 bounty. Sol Vega runs packages for fixer Dom Reyes in the coastal city of Tidewater: walk or drive any car, dodge traffic, outrun a 0–5 star wanted system with police interceptors, and deliver against the clock while the payouts grow.

Play it with `node serve.ts`, then open http://localhost:8080.
